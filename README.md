## 🚀 Core Project

### [⛰️ 산결 (Sangyeol)](https://github.com/JNU-econovation/sangyeol-backend)
> **"실시간 위치 기반 산행 이벤트 처리와 안정적인 인증 인프라 구축"** <br>
> 등산 기록 및 실시간 이벤트 관리를 담당하는 백엔드 서비스입니다.

- **Tech Stack**: Java 21, Spring Boot 3.3.1, MySQL, Redis, QueryDSL, WebSocket, AWS S3
- **Key Roles**:
  - WebSocket을 활용한 실시간 산행 상태(시작, 일시정지, 재개, 종료) 및 이벤트 라우팅 처리
  - Redis를 활용한 JWT 토큰 관리 및 블랙리스트 처리, 랜덤 닉네임 풀 구현
  - AWS S3 Presigned URL을 이용한 프로필 이미지 관리
  - QueryDSL 기반 코스 및 산행 정보 정렬, 조인 조회 최적화
